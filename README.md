# Customer Churn & Revenue Impact Analysis

## Project Overview
This is a tutorial-guided data analytics project focused on analysing customer churn and its potential revenue impact using Python and SQL. The analysis was performed using Jupyter Notebook.

## Project Objectives
- Understand customer churn and retention patterns.
- Analyse customer, subscription and support data.
- Identify metrics associated with customer churn.
- Explore potential revenue at risk.

## Tools & Technologies
- Python
- SQL (SQLite)
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Connected Python to an SQLite database and imported multiple tables.
2. Performed data exploration and data cleaning.
3. Combined customer, subscription and support datasets.
4. Created features such as customer age, tenure, churn flags and churn-risk categories.
5. Calculated key performance indicators (KPIs).
6. Performed exploratory data analysis (EDA).
7. Created visualisations to explore churn trends and relationships between metrics.

## Key Findings
- Churn Rate: 28.57%
- Retention Rate: 71.43%
- Escalation Rate: 19.05%
- Correlation between escalations and churn: 0.77

*These findings describe the analysed dataset and do not establish causation.*
